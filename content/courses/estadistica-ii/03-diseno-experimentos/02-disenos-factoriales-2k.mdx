# Introducción

> En ingeniería de procesos, cuando debemos tamizar 3, 4 o 5 factores potencialmente influyentes (temperatura, presión, tiempo, concentración), los **diseños $2^k$** son la herramienta reina de cribado inicial (screening).

Un diseño $2^k$ evalúa $k$ factores a solo 2 niveles cada uno: nivel bajo ($-1$) y nivel alto ($+1$), requiriendo únicamente $2^k$ corridas experimentales por réplica.

<Callout type="info">
**El Principio de Parsimonia (Esparcidad de Efectos):** En la mayoría de los sistemas industriales, el 80% de la variabilidad observada se debe a unos pocos efectos principales e interacciones de dos factores; las interacciones de tres o más factores casi siempre son despreciables.
</Callout>

# 1. Matriz de Diseño para un Experimento $2^2$

Consideremos 2 factores: $A$ (Temperatura) y $B$ (Presión):

| Tratamiento | A | B | Notación Estándar |
| :--- | :---: | :---: | :---: |
| 1 | $-$ | $-$ | $(1)$ |
| 2 | $+$ | $-$ | $a$ |
| 3 | $-$ | $+$ | $b$ |
| 4 | $+$ | $+$ | $ab$ |

### Cálculo del Efecto Principal de A:
$$Efecto(A) = \frac{1}{2n} [ab + a - b - (1)]$$

### Cálculo del Efecto de Interacción AB:
$$Efecto(AB) = \frac{1}{2n} [ab + (1) - a - b]$$

# 2. Laboratorio en Python: Ajuste de un Diseño $2^3$

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

# Diseño 2^3 con réplicas (Factores: A=Temp, B=Presión, C=Tiempo)
df = pd.DataFrame({
    'A': [-1,  1, -1,  1, -1,  1, -1,  1] * 2,
    'B': [-1, -1,  1,  1, -1, -1,  1,  1] * 2,
    'C': [-1, -1, -1, -1,  1,  1,  1,  1] * 2,
    'Rendimiento': [
        55, 72, 60, 85, 59, 77, 66, 93,
        53, 70, 62, 83, 61, 79, 64, 91
    ]
})

# Ajuste con todas las interacciones
modelo = ols('Rendimiento ~ A * B * C', data=df).fit()
print(modelo.summary())

# Los coeficientes de la regresión equivalen a la mitad del efecto del factor
efectos = modelo.params.drop('Intercept') * 2
print("\nEfectos de los Factores (2 * Coef):")
print(efectos.sort_values(key=abs, ascending=False))
```
