# Introducción

> Un proceso puede estar en perfecto control estadístico (muy estable) pero generar un 20% de piezas defectuosas si la varianza es demasiado amplia para la tolerancia exigida. ¡Estar en control no significa ser capaz!

El **Análisis de Capacidad del Proceso** compara la amplitud de la tolerancia especificada por el diseño ($LSE - LIE$) contra la variabilidad natural del proceso ($6\sigma$).

<Callout type="info">
**Condición Previa Obligatoria:** El cálculo de $C_p$ y $C_{pk}$ solo tiene validez estadística si el proceso está en **estado de control estadístico** y la variable respuesta sigue una distribución aproximadamente **normal**.
</Callout>

## Objetivos de Aprendizaje
- Calcular e interpretar el índice de capacidad potencial $C_p$.
- Calcular e interpretar el índice de capacidad real y centrado $C_{pk}$.
- Relacionar los valores de $C_{pk}$ con las partes por millón defectuosas (PPM) y el nivel de calidad Six Sigma.

---

# 1. Los Índices $C_p$ y $C_{pk}$

### 1. Índice de Capacidad Potencial ($C_p$)
Mide qué tan estrecha es la dispersión del proceso en relación con la tolerancia, asumiendo un centrado perfecto:
$$C_p = \frac{LSE - LIE}{6\sigma}$$

### 2. Índice de Capacidad Real ($C_{pk}$)
Toma en cuenta el posible descentrado de la media $\mu$ del proceso respecto al valor nominal:
$$C_{pk} = \min\left( \frac{LSE - \mu}{3\sigma}, \frac{\mu - LIE}{3\sigma} \right)$$

<Callout type="note">
**Regla de Interpretación:**
- $C_{pk} < 1.0$: Proceso **incapaz**. Se fabrican piezas defectuosas fuera de especificación.
- $1.0 \le C_{pk} < 1.33$: Proceso **apenas adecuado** (requiere monitoreo estricto).
- $C_{pk} \ge 1.33$: Proceso **capaz y satisfactorio** (estándar industrial común).
- $C_{pk} \ge 1.67$ a $2.0$: Calidad **Six Sigma** ($C_p = 2.0$, $C_{pk} \ge 1.5$ con corrimiento de $1.5\sigma$, resultando en solo 3.4 PPM).
</Callout>

---

# 2. Relación entre $C_p$ y $C_{pk}$

- Si $C_p = C_{pk}$: El proceso está **perfectamente centrado** en el punto medio de las especificaciones.
- Si $C_{pk} < C_p$: El proceso está **descentrado** hacia uno de los límites.
- Si $C_{pk} \le 0$: La media del proceso está por fuera de las especificaciones.

# 3. Código en Python

```python
import numpy as np
from scipy import stats

# Proceso de llenado de botellas (ml)
# Especificaciones: LIE = 495 ml, LSE = 505 ml, Nominal = 500 ml
LIE = 495.0
LSE = 505.0

# Muestra de 100 botellas inspeccionadas
np.random.seed(42)
datos = np.random.normal(loc=501.2, scale=1.4, size=100)

mu = np.mean(datos)
sigma = np.std(datos, ddof=1)

# Cálculo de índices
Cp = (LSE - LIE) / (6 * sigma)
Cpu = (LSE - mu) / (3 * sigma)
Cpl = (mu - LIE) / (3 * sigma)
Cpk = min(Cpu, Cpl)

# Fracción defectuosa esperada (PPM)
prob_defecto = stats.norm.cdf(LIE, mu, sigma) + (1 - stats.norm.cdf(LSE, mu, sigma))
ppm = prob_defecto * 1_000_000

print(f"Media: {mu:.3f} ml, Desv. Estándar: {sigma:.3f} ml")
print(f"Cp  = {Cp:.3f}")
print(f"Cpk = {Cpk:.3f}")
print(f"Defectos esperados: {ppm:.1f} PPM ({prob_defecto*100:.4f}%)")
```
