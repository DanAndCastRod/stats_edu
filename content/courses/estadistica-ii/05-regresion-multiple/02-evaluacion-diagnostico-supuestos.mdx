# Introducción

> "Todos los modelos son erróneos, pero algunos son útiles." — George Box. Un modelo de regresión con un $R^2$ del 98% puede ser completamente engañoso si viola los supuestos de homocedasticidad o si sus predictores están fuertemente colineales.

El **diagnóstico de regresión** evalúa la validez de los cuatro supuestos fundamentales de Gauss-Markov sobre los residuos $\epsilon_i$:
1. **Linealidad:** $E[\epsilon_i] = 0$.
2. **Homocedasticidad:** $Var(\epsilon_i) = \sigma^2$ (varianza constante).
3. **Independencia:** $Cov(\epsilon_i, \epsilon_j) = 0$.
4. **Normalidad:** $\epsilon_i \sim N(0, \sigma^2)$ (para inferencia e intervalos).

<Callout type="info">
**Multicolinealidad:** Ocurre cuando dos o más variables independientes están altamente correlacionadas entre sí, inflando las varianzas de los estimadores $\beta_j$ y haciendo que los coeficientes sean inestables e interpretables erróneamente.
</Callout>

# 2. Factor de Inflación de Varianza (VIF)

Para la variable predictora $X_j$:

$$VIF_j = \frac{1}{1 - R_j^2}$$

Donde $R_j^2$ es el coeficiente de determinación obtenido al regresar $X_j$ sobre todas las demás variables predictoras.

| Rango de VIF | Diagnóstico |
| :--- | :--- |
| $VIF \approx 1$ | Variables completamente ortogonales (sin colinealidad). |
| $1 < VIF < 5$ | Colinealidad moderada (tolerable en la práctica). |
| $VIF \ge 5 - 10$ | **Multicolinealidad severa.** Se recomienda eliminar variables redundantes o usar Regresión Ridge/Lasso. |

# 3. Código en Python con `statsmodels`

```python
import pandas as pd
from statsmodels.stats.outliers_influence import variance_inflation_factor
import statsmodels.api as sm

# DataFrame con variables predictoras
df_X = pd.DataFrame({
    'Temp_C': [20, 22, 24, 25, 28, 30, 32, 35],
    'Temp_F': [68, 71.6, 75.2, 77, 82.4, 86, 89.6, 95],  # Colinealidad casi perfecta
    'Presion': [100, 102, 101, 105, 108, 110, 112, 115]
})

X_const = sm.add_constant(df_X)

vif_data = pd.DataFrame()
vif_data["Variable"] = X_const.columns
vif_data["VIF"] = [variance_inflation_factor(X_const.values, i) for i in range(X_const.shape[1])]

print(vif_data[vif_data['Variable'] != 'const'])
```
