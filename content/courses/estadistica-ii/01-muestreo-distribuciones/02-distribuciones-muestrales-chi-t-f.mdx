# Introducción

> ¿Cómo sabemos si dos máquinas tienen la misma precisión o si un nuevo tratamiento reduce la dispersión de un proceso químico? La respuesta reside en el cociente de varianzas y la distribución F de Fisher-Snedecor.

Cuando tomamos muestras de una población normal $N(\mu, \sigma^2)$, surgen de manera natural tres distribuciones muestrales continuas derivadas: $\chi^2$, Student-$t$ y Fisher-$F$.

<Callout type="info">
**El Teorema de Fisher:** Si $X_1, \dots, X_n \sim N(\mu, \sigma^2)$ independientes, la media muestral $\bar{X}$ y la varianza muestral $S^2$ son **estocásticamente independientes**.
</Callout>

## Objetivos de Aprendizaje
- Comprender la relación matemática entre la normal estándar y las distribuciones $\chi^2$, $t$ y $F$.
- Utilizar la distribución F para contrastar razones de varianzas poblacionales $\sigma_1^2 / \sigma_2^2$.
- Explorar de forma interactiva el efecto de los grados de libertad en la cola de la distribución F.

# 1. Definiciones Teóricas Fundamentales

### 1. Distribución Chi-Cuadrado ($\chi^2$)
Si $Z_1, \dots, Z_k \sim N(0, 1)$ independientes:
$$Y = \sum_{i=1}^k Z_i^2 \sim \chi^2(k)$$
Para la varianza muestral de una muestra normal:
$$\frac{(n - 1)S^2}{\sigma^2} \sim \chi^2(n - 1)$$

### 2. Distribución t de Student
Cociente entre una Normal Estándar y la raíz de una Chi-Cuadrado independiente:
$$T = \frac{Z}{\sqrt{\chi^2(k) / k}} \sim t(k)$$

### 3. Distribución F de Snedecor
Cociente entre dos variables Chi-Cuadrado independientes divididas por sus grados de libertad:
$$F = \frac{\chi_1^2 / d_1}{\chi_2^2 / d_2} \sim F(d_1, d_2)$$

Para dos muestras independientes con varianzas $S_1^2$ y $S_2^2$:
$$F = \frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2}$$

  initialCode={`import numpy as np
from scipy import stats

# Prueba de razón de varianzas entre dos métodos de manufactura en planta
muestra_A = np.array([12.4, 12.1, 12.8, 12.5, 12.9, 12.3])
muestra_B = np.array([11.8, 12.9, 11.2, 13.5, 12.0, 13.8, 11.4])

s1_sq = float(np.var(muestra_A, ddof=1))
s2_sq = float(np.var(muestra_B, ddof=1))
df1 = len(muestra_A) - 1
df2 = len(muestra_B) - 1

# Estadístico F
f_stat = s1_sq / s2_sq if s1_sq > s2_sq else s2_sq / s1_sq
p_value = 2.0 * (1.0 - stats.f.cdf(f_stat, df1, df2))

print(f"--- ANÁLISIS DE VARIANZAS MUESTRALES (F-TEST) ---")
print(f"Muestra A (n={len(muestra_A)}): Media={np.mean(muestra_A):.2f}, Varianza={s1_sq:.4f}")
print(f"Muestra B (n={len(muestra_B)}): Media={np.mean(muestra_B):.2f}, Varianza={s2_sq:.4f}")
print(f"Estadístico F calculado: {f_stat:.4f} (df1={df1}, df2={df2})")
print(f"P-valor bilateral: {p_value:.5f}")

alpha = 0.05
f_critico = float(stats.f.ppf(1.0 - alpha / 2, df1, df2))
print(f"Valor crítico F_(0.025): {f_critico:.4f}")

if f_stat > f_critico:
    print(">> DECISIÓN: Se rechaza H0. Hay evidencia estadística de varianzas heterogéneas.")
else:
    print(">> DECISIÓN: No se rechaza H0. No hay evidencia de diferencia en la dispersión.")
`}
