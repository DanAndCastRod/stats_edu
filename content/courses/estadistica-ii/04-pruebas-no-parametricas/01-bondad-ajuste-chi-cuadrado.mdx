# Introducción

> ¿Cómo sabemos si un dado está cargado, si los clientes llegan siguiendo una distribución Poisson o si el tipo de fallo de una máquina es independiente del turno de trabajo?

La prueba **$\chi^2$ de Pearson** permite contrastar si una distribución de frecuencias observadas discreta o categorizada coincide con una distribución teórica esperada.

<Callout type="info">
**El Estadístico Chi-Cuadrado de Pearson:**
$$\chi^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i}$$
Donde $O_i$ son las frecuencias observadas y $E_i$ las frecuencias esperadas bajo la hipótesis nula $H_0$.
</Callout>

# 1. Tablas de Contingencia e Independencia

Para una tabla con $r$ filas y $c$ columnas:

$$E_{ij} = \frac{\text{Total Fila } i \times \text{Total Columna } j}{N}$$

El estadístico resultante tiene $(r - 1)(c - 1)$ grados de libertad:

$$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \sim \chi^2((r - 1)(c - 1))$$

<Callout type="warning">
**Condición de Cochran:** Para que la aproximación $\chi^2$ sea válida, no más del 20% de las celdas deben tener $E_{ij} < 5$, y ninguna celda debe tener $E_{ij} < 1$.
</Callout>

# 3. Código en Python con `scipy.stats`

```python
import numpy as np
from scipy import stats

# Tabla de contingencia: Turno vs Tipo de Defecto
# Filas: Mañana, Tarde, Noche
# Columnas: Eléctrico, Mecánico, Pintura
tabla_observada = np.array([
    [45, 30, 25],
    [50, 40, 30],
    [35, 55, 40]
])

chi2_stat, p_val, dof, esperados = stats.chi2_contingency(tabla_observada)

print(f"Estadístico Chi-Cuadrado: {chi2_stat:.4f}")
print(f"Grados de libertad: {dof}")
print(f"p-valor: {p_val:.4f}")
print("\nFrecuencias Esperadas:")
print(np.round(esperados, 2))
```
